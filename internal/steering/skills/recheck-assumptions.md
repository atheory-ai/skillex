# Recheck assumptions

When two fixes based on the same assumption fail the same check, state what both fixes assumed. Choose a small observation that would differ if the assumption were false. Inspect the real inputs, state, or output at the point where the explanations diverge.

Record what you observed. If it contradicts the assumption, revise the explanation before editing again. If the observation is inconclusive, name what remains unknown and choose a check that can distinguish the remaining explanations.
